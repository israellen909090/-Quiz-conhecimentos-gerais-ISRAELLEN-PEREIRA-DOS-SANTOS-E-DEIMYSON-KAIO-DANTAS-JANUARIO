 Quiz de Conhecimentos Gerais
 Sobre o aplicativo

O Quiz de Conhecimentos Gerais é um joguinho feito em Python para testar os conhecimentos dos participantes. Ele possui 10 perguntas de nível intermediário, cada uma com quatro alternativas, mas apenas uma está correta.

No final, o jogador descobre quantos pontos conseguiu fazer e recebe uma classificação de acordo com seu resultado.

 Como funciona?
O jogador pode iniciar o quiz pelo menu.
São apresentadas 10 perguntas com quatro alternativas.
As perguntas aparecem em ordem aleatória.
Cada resposta certa vale 1 ponto.
No final, aparece a pontuação e a classificação do jogador.
 Assuntos das perguntas

O quiz tem perguntas sobre:

História;
Geografia;
Ciências;
Literatura;
Conhecimentos gerais.
 O que usamos para fazer?
Python 3;
Biblioteca random, para embaralhar as perguntas.
 Como jogar?
Instale o Python no computador.
Baixe o arquivo quiz.py.
Abra o terminal na pasta onde o arquivo está.
Digite:
bash
python quiz.py

Escolha uma opção no menu e divirta-se!
 Classificação
8 a 10 pontos: Parabéns! Você conhece o básico!
5 a 7 pontos: Mais ou menos! Melhore!
3 a 4 pontos: Vamos estudar?
0 a 2 pontos: Vixi! Desista!
